Cahier des Charges – Application de Location de Parking entre Particuliers

1. Présentation du projet
Le projet consiste à développer une application mobile et une interface web permettant la mise en relation entre particuliers pour la location de places de parking.
L'application doit permettre :
- Aux utilisateurs de trouver et réserver une place de parking.
- Aux propriétaires de mettre en location leur place de parking.
- À l’administrateur de gérer les utilisateurs, les parkings et les réservations.

2. Objectifs
- Offrir une solution simple et accessible pour la location de parkings.
- Permettre une expérience fluide sur mobile (front office).
- Fournir un back-office pour l’administration et le suivi des transactions.
- Créer une base technique évolutive (ajout futur : paiements en ligne, QR codes, authentification sociale).

3. Public cible
- Locataires : particuliers, administrations ou sociétés cherchant une ou des places de parking.
- Propriétaires : particuliers, administrations ou sociétés disposant d’une place disponible.
- Administrateur : gère la plateforme.

4. Fonctionnalités principales
4.1 Mobile – Front Office (utilisateur)
Authentification
- Inscription utilisateur (email, mot de passe, téléphone, éventuellement Google/Apple à prévoir plus tard).
- Connexion sécurisée (JWT/token côté mobile).
- Mot de passe oublié (reset par email).
Page d’accueil – Recherche de parking
- Saisie d’adresse (barre de recherche).
- Carte interactive (Google Maps / Leaflet) avec marqueurs de parkings disponibles.
- Filtres avancés :
- Date & Heure d’arrivée/départ
- Prix (intervalle)
- Type de véhicule (moto, voiture, utilitaire, etc.)
- Options (gardiennage, couverture, recharge électrique)
- Liste des parkings triable (prix, distance, disponibilité)
Détail d’un parking
- Photos (carousel)
- Adresse précise (+ lien Google Maps)
- Prix par heure / par jour
- Disponibilité (en temps réel)
- Description (sécurité, accès, taille, services inclus)
- Avis/notes utilisateurs
- Bouton "Réserver"
Réservation
- Sélection de la période (date et heure de début + fin)
- Récapitulatif réservation (parking, période, prix total)
- Confirmation avec :
- Moyen de paiement (au début "payer sur place", puis plus tard Stripe/Orange Money)
- Génération d’un QR Code ou code unique (pour validation à l’entrée)
Mes réservations
- Liste des réservations avec :
- Parking réservé (nom + adresse)
- Période
- Prix payé
- Statut : À venir (vert), En cours (bleu), Terminé (gris), Annulé (rouge)
- Filtres : par statut, par date
- Historique complet

4.2 Web – Back Office (admin)
Authentification
- Connexion sécurisée (email + mot de passe, JWT ou cookies sécurisés)
- Mot de passe oublié / reset par email
- Gestion des rôles : Admin principal, opérateur simple, futur super admin
Tableau de bord
- Statistiques globales :
- Total des commissions générées (jour / mois / global)
- Nombre de réservations par statut
- Classement des parkings les plus loués
- Nombre d’utilisateurs actifs
Gestion des types de véhicules (CRUD)
- Ajouter / modifier / supprimer un type de véhicule :
- Nom (ex : Moto, Citadine, SUV, Utilitaire, Camion)
- Taille max (optionnel)
- Association du type de véhicule aux parkings
Gestion des commissions (CRUD)
- Définir un pourcentage de commission global (ex : 10%)
- Définir un pourcentage par type de parking ou partenaire (optionnel)
- Historique des modifications
Gestion des réservations
- Liste des réservations avec filtres :
- Par statut, utilisateur, partenaire, période
- Détail d’une réservation :
- Parking réservé, utilisateur, montant payé, commission perçue
- Paramétrage des délais de réservation

6. Technologies envisagées
- Backend : NodeJS avec PostgreSQL et MongoDB
- Mobile : React Native ou Flutter
- Web admin : ReactJS
- Hébergement : Cloud (Azure, AWS ou VPS local)

7. Organisation de l’équipe
