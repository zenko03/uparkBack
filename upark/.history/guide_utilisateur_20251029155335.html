Gestion des Triggers de Restriction SAGE

Guide Utilisateur – Version Professionnelle

Avant de commencer : Première utilisation

Lors du premier lancement de l’application, suivez ces étapes :

  1. Configuration de la connexion à la base SAGE
    Une fenêtre s’ouvre pour saisir les informations SQL Server (serveur, base, utilisateur, mot de passe).
    Validez → l’application redémarre.
  2. Installation des tables et triggers
    Menu Paramètres → Installation de la Base de Données.
    Message de confirmation en cas de succès.
  3. Modification de la connexion
    Paramètres > Configuration de la Connexion → redémarrage requis.

1. Introduction

1.1. Objectif de l’application

L’outil permet de sécuriser et automatiser la gestion des documents d’achat à bon d’import (DABI) dans SAGE Gestion Commerciale.

Objectifs principaux :

  • Contrôler les souches d’achat pour DABI
  • Restreindre l’accès aux tiers par utilisateur
  • Limiter les articles saisis en DABI
  • Activer/désactiver les triggers SQL en temps réel

1.2. Interface principale

Bouton Fonction
Souches Achat Définir les souches autorisées ou exclusives pour DABI
Restrictions Tiers Assigner des fournisseurs à chaque utilisateur
Articles DABI Gérer articles et utilisateurs autorisés DABI
Status Trigger Activer/désactiver les triggers SQL

2. Module 1 : Gérer les Souches DABI

2.1. Accès et interface

Cliquez sur Souches Achat.

ID Intitulé Statut DABI Journal
1 Achat LOCAL DABI Autorisé ACH
2 Achat IMPORT DABI Exclusif ACHIMP
3 Achat SERVICES Non configuré ACHSER

2.2. Statuts DABI

Statut Signification
DABI Exclusif Souche réservée uniquement aux DABI
DABI Autorisé Utilisable pour DABI et documents standards
Non configuré Comportement SAGE standard
Note : Le statut DABI Exclusif est affiché en rouge.

2.3. Configurer une souche

  1. Sélectionner une ligne → Configurer DABI
  2. Fenêtre de configuration :
[ ] Activer la restriction DABI
[ ] Souche DABI exclusive

[Enregistrer] [Annuler]
  • DABI Autorisé → Cocher uniquement la 1ʳᵉ case
  • DABI Exclusif → Cocher les deux cases

4. Module 3 : Gérer les Articles DABI

Deux listes indépendantes :

  • Articles autorisés pour DABI
  • Utilisateurs autorisés à saisir des DABI
Important : Utilisateur non autorisé OU article non autorisé = saisie impossible.

4.1. Interface

Onglets :

  • Articles DABI : cases à cocher + [Rechercher] + [Sauvegarder]
  • Utilisateurs DABI : idem

Administrateurs SAGE : exemptés des restrictions.

5. Module 4 : Gestion des Triggers SQL

Cliquez sur Status Trigger.

Trigger Fonction
TR_DABI_SOUCHE_RESTRICTION Contrôle des souches
TR_DABI_ARTICLE_RESTRICTION Contrôle des articles
TR_DABI_ARTICLE_DELETE Protection contre suppression

Cocher/décocher → Sauvegarder

6. Fonctionnalités communes

Fonction Description
Rechercher Filtre dynamique
Actualiser Recharge données (F5)
Exporter Fichier CSV (Excel)

7. Vérification du statut des triggers

Via Status Trigger → état en temps réel.
Désactivé = aucune restriction appliquée.
